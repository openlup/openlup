# Installed agent context MVP task

Status: local implementation in progress; development preview.

Outcome: an adopter can retrieve a small set of source-backed task guidance
from its installed package set without a network service. Scope is a bounded
generated Markdown corpus for core, outbox and platform, an installed retrieval
command, focused witnesses and package inclusion. Canonical owners remain the
authoring source. Excluded: embeddings, graph storage, hosted services, broad
documentation duplication and any stable-framework or deployment qualification.

Acceptance: generation is deterministic and bounded; every excerpt binds exact
canonical bytes with source path, line span and SHA-256; freshness refuses
drift without writes; an installed consumer retrieves guidance offline; package
and documentation checks preserve existing version boundaries. Verification
uses focused generator/retrieval witnesses, installed-consumer evidence and
the existing repository gates. Package inclusion must use tracked Markdown;
prepack must not generate corpus files. Relative excerpt links intentionally
retain the original source base rather than imply all linked files ship.
