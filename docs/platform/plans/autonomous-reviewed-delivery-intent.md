# Intent: autonomous delivery with accountable review

Status: historical record, 2026-11-06.

Recorded status: historical intent; current delivery and review rules are in [Deliver a change](../../../CONTRIBUTING.md#deliver-a-change).

The intent was to let authorized contributors complete bounded changes with
independent review under existing subscriptions, while retaining human
accountability, DCO and actual delivery authority. Required CI verifies the
integration tree; review evidence does not grant release or settings rights.

The [historical implementation plan](autonomous-reviewed-delivery.md) records the
native session and queue-admission work. Current instructions are maintained only
in CONTRIBUTING rather than repeated here.
