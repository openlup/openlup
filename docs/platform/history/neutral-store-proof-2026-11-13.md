# Starter execution evidence archive

Status: historical evidence, 2026-11-13; archived on 2026-11-17.

The [complete original proof record](neutral-store-proof-2026-11-13.txt) is
preserved byte for byte as plain text, including all dated results, commands,
headings and original link destinations. Resolve those relative destinations
from its original location, `examples/neutral-store/docs/proof.md`.

The text attachment keeps frozen application commands separate from executable
repository Markdown recipes: the publication check interprets Markdown commands
relative to their owning package, which changes when a record moves here.
No command or historical result has been rewritten to fit the archive location.

For a new candidate use the [current starter verification recipe](../../../examples/neutral-store/docs/proof.md).
The [reader guide](../../../packages/core/docs/guide/reference/limits.md) owns
current limits. The archived record supplies no current installation, provider,
release or stable-framework qualification.
