Stable API under SemVer from 1.0.0. Unions and literal sets are open: adding a value is minor; consumers must keep a default branch for unknown values. Removing, renaming or narrowing an export, value or type is major. Symbols tagged @experimental within a stable subpath are outside this promise.

Generated by `node --experimental-strip-types ./scripts/api-contract.ts --update`. Every change requires explicit review.
