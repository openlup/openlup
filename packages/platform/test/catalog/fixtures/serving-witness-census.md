## Contract choices

| Choice | Expected result |
|---|---|
| C-Q | Keep the exact typed quantity and independent gross mass. Legacy conversion refuses non-mass, fractional or out-of-range values with `quantity_requires_v2`. |
| C-READ | Listing, detail, quote and editor read the same verified publication facts. An observed empty result is distinct from unavailable authority. |
| C-REG | Resolve the configuration from one registration. Duplicate and unknown configurations refuse before any selection. |
| C-READY | A read capability requires observed compatible authority and an explicit binding. Writer disable preserves qualified reads and retained servicing. |

The SQL witness compares the installed compatibility constraint, nullability, and grants as a single schema shape. The retained display cases compare frozen order quantity and money independently of typed content.
