### Company identity and market preservation candidate

Adds experimental company-identity, company-identity/contracts,
company-identity/server and market-packs subpaths. They preserve the existing
lookup provider order, registry extensions, shared cache and pure settlement,
fiscal and formatting behaviour. Core contracts and reference callers retain
their existing owners. The handler accepts the host's existing BFF responder and optional identity rules.

Migration: no application import, environment key, persisted key, SQL or version
changes in this draft. Country, currency, fiscal and display facts are explicit caller inputs;
replaceable policy and reference delegation follow separately. No release or
all-market qualification is implied.
