Adds an experimental trusted catalogue projection command and typed source
contract. It writes a deterministic scratch subject outside the application
and records its hash, timings and the single checker invocation. The checker
uses the installed draft schemas through v5, the catalogue content validator
from the trusted registry, profile binding and an independently executed
prepaid refusal. Installed recipes cover the runtime pack scaffold and discovery.

Migration: Existing JSON checker invocations, report version and exit codes
remain supported. To check runtime packs, register them once in the application's
trusted catalogue module and use the installed projection command. Static JSON
never grants callback authority. Offline results grant no installation or
publication authority. Taxonomy, tax application and promotions remain unavailable.
