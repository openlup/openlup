### Connected settings require an explicit PostgreSQL target

- For `openlup settings show` and `preview`, supply a canonical PostgreSQL URL with one TCP host, a username and a single database path segment. Use a DNS name of at most 253 characters with labels of at most 63 characters or write IPv4 octets in decimal without leading zeros. Use at most 63 UTF-8 bytes each for the decoded username and database name. The only supported query option is `sslmode` with `disable`, `require` or `verify-full`. Omitting it selects plaintext.
- For a connected read, the launcher's pool removes `PG`-prefixed environment variables immediately before creating each client. It skips password files by supplying an empty password if the URL omits one. Applications that replace the driver or pool manage their own connection settings. Connected settings commands refuse when `NODE_PG_FORCE_NATIVE` is nonempty. Unset it to use the JavaScript driver.
- The experimental `runSettingsCommand` host binding receives admitted connection options in `bind({ database })` in place of `bind({ databaseUrl })`.
