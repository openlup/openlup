### Opt-in reference payment repair view

The reference store displays repair for the existing checkout identity through the status-only `commerce/paymentStatusClient`, customer `commerce/paymentVerifyClient` and shared `payment/components/PaymentStatusPoller` modules. Only stored paid status confirms payment. Redirect handoff links render only for HTTPS URLs. Host collection and confirmation remain injected; unsupported method setup is visible. Exact file/specifier guardrail exemptions refuse the broader `commerceClient` and operator clients, and a source-import test proves the store stays unmounted in the shipped default profile.

Migration: none. No new export, route activation, dependency or payment control change.
