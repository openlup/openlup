Migration: Native subscription activation now requires explicit EXECUTE: PUBLIC no longer executes the base activation entry and commit functions. The qualified runtime login (through `service_role`) and the owner keep access. A custom activation role needs the grants in the [operator grant matrix](https://github.com/openlup/openlup/blob/main/docs/platform/DATA_AND_MIGRATIONS.md#native-activation-execute-grants); recheck each path with the same login.
