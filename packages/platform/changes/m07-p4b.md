### Payment conformance redaction scan

Adapter conformance no longer treats an empty optional transient value, such as an empty payer name, as a leak, and it detects JSON-escaped forms of transient values in execution diagnostics, readbacks and stored payloads, and of payer contact in execution results.

Migration: none. An adapter that was refused only because a fixture used an empty optional transient value now passes; an adapter that leaked an escaped transient value is now refused.
