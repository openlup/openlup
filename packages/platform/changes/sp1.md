Adds experimental versioned subscription profile declarations and an explicit
policy binding for neutral cadence, quantity, add-on, exact swap and demand
admission. Count and mass coverage can share a cadence while retaining independent
daily rates. Profiles can narrow eligibility. A proposal leaves schedule ownership
with the accepted commerce command.

Migration: Keep historical profile versions and policy builds composed. Existing
pack snapshots without full declarations keep their canonical bytes. Offline
validation applies a 120-day package maximum. Native activation also requires
the installed edit bound on the same database. Definition validation and binding
are available as unbound contracts. Verify transactional support for a profile
before enabling a purchase or edit lane.

Native installation retains the canonical profile declaration in the existing
install receipt and refuses a change at the same profile version. The shared
purchase and edit fence refuses a selected profile while transactional profile
acceptance is unavailable. The managed rail does not supply this feature. A
managed twin can retain definitions in its install ledger under RLS, give
definition writes to its installer role, and verify profile admission under its
existing order and edit authorities.
