`@openlup/platform/pricing/browser` also exports `acquisitionTermsSchema` and `deriveSubscriptionUnitPrice`, the same objects as on `@openlup/platform/pricing`. Browser code should import them from the browser entry. `deriveSubscriptionUnitPrice` is a display estimate; the quote is the amount charged. The module that defines it sets zod to `jitless`, as the server entry does; bundles that import only the entry's earlier symbols do not contain that call.
