- Starter hardening. The local demonstration provisions an individual PostgreSQL runtime credential for each Compose project. The runtime credential file must stay in owner-only configuration. The starter validates it at start.

Migration: Stop the application. Follow the [adjacent-release starter upgrade](https://github.com/openlup/openlup/blob/d1214a43f5ebbb51be2b737dfa1956a247414206/packages/core/docs/guide/upgrade/README.md#starter-upgrade-order) and reconcile any locally changed Compose or installation files. Run the updated `./lifecycle up` in the same Compose project to provision its credential and start the application with the existing database volume. Verify application health. If startup reports a credential-source problem, restore access to the private project credential and rerun the updated lifecycle command. Run the local renewal, care and checkout recovery commands through the application container as shown in the starter guide.
