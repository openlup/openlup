# AI-assisted contributions

You can use AI assistance when contributing to OpenLup. If you use a tool to
prepare a contribution, these rules explain what you remain responsible for.

## The four rules

1. **Disclose AI assistance.** Say in the pull request or issue if a tool wrote,
   drafted or materially shaped your contribution. A checkbox is enough;
   AI assistance alone does not count against you.

2. **Keep a human accountable.** Each contribution must have exactly one human
   author who answers for it. Using an agent does not transfer that
   responsibility to the tool.

3. **Be able to explain every line.** You must be able to explain why each line
   exists when asked. If your only explanation is that the model wrote it, the
   contribution is not ready.

4. **Stay within authorized scope.** An agent can implement and independently
   review an authorized task. Opening or merging a pull request requires the
   applicable explicit maintainer authority. Generated plans and automated
   reviews cannot grant that authority.

For sign-off, submission and review procedures, follow the
[AI contribution policy](https://github.com/openlup/openlup/blob/openlup-core-v0.39.0/.github/AI_CONTRIBUTION_POLICY.md#admission-native-review-and-dco)
and [contribution instructions](https://github.com/openlup/openlup/blob/openlup-core-v0.39.0/CONTRIBUTING.md#deliver-a-change).
